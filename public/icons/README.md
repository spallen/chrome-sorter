# Extension Icons

Place your extension icons in this directory with the following sizes:

- `icon16.png` - 16x16 pixels
- `icon32.png` - 32x32 pixels
- `icon48.png` - 48x48 pixels
- `icon128.png` - 128x128 pixels

You can create these icons using tools like:
- Figma
- Adobe Illustrator
- Canva
- Online icon generators

The icons should represent your extension's brand and be easily recognizable in the browser toolbar and extension management page.

For now, you can use placeholder images or create simple icons with a list/sorting theme to match the extension's purpose.
